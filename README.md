# Hilton Case Técnico

Sistema de Matriz Curricular e Matrícula.

Desafio técnico — gestão de matriz curricular, controle de acesso e matrícula,
com backend em Kotlin/Quarkus, frontend em Angular/Nx e autenticação via Keycloak.

## Pré-requisitos

- Docker e Docker Compose

## Como subir

\`\`\`bash
docker compose up --build
\`\`\`

## URLs

- Backend: http://localhost:8080
- Swagger: http://localhost:8080/q/swagger-ui
- Frontend: http://localhost:4200
- Keycloak: http://localhost:8081
